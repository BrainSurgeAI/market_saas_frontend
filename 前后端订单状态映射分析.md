# 前后端订单状态映射分析

## 后端状态（Rust）→ 前端状态（TypeScript）映射

### 普通流程（Normal Flows）

| 后端 (Rust) | 前端 (TS) | 描述 | 租户 |
|-----------|---------|------|------|
| Pending | PENDING | 客户创建，订单初始状态 | 客户 |
| Assigned | ASSIGNED | 已分配给供应商 | 市场 |
| SupplierPreparing | SUPPLIER_PREPARING | 供应商确认，开始备货 | 供应商 |
| SupplierDelivering | SUPPLIER_DELIVERING | 备货完成，配送到市场 | 供应商 |
| MarketInspecting | MARKET_INSPECTING | 市场开始验货 | 市场 |
| MarketAccepted | MARKET_ACCEPTED | 验收完成，无退换货 | 市场 |
| MarketDelivering | MARKET_DELIVERING | 开始送货到客户 | 市场 |
| CustomerInspecting | CUSTOMER_INSPECTING | 客户开始验货 | 客户 |
| Completed | COMPLETED | 完成订单，无退换货 | 客户 |

### 退货流程（Return Flow）

| 后端 (Rust) | 前端 (TS) | 描述 |
|-----------|---------|------|
| ReturnRequested | AFTER_SALE | 申请退货 |
| Returned | RETURNED | 退货完成 |

**⚠️ 前端使用 `AFTER_SALE` 可能需要重命名为 `RETURN_REQUESTED`**

### 换货流程（Exchange Flow）

| 后端 (Rust) | 前端 (TS) | 描述 | 租户 |
|-----------|---------|------|------|
| ExchangeRequested | EXCHANGE_REQUESTED | 申请换货 | 市场/客户 |
| ExchangeInProgress | EXCHANGE_IN_PROGRESS | 换货进行中，供应商备货 | 供应商 |
| ExchangeDelivering | EXCHANGE_DELIVERING | 换货商品配送中（到市场） | 供应商 |
| ExchangeInspecting | EXCHANGE_INSPECTING | 市场检验换货商品 | 市场 |
| ExchangeNewDelivering | EXCHANGE_NEW_DELIVERING | 新商品配送中 | 市场 |
| ExchangeCompleted | EXCHANGE_COMPLETED | 换货完成 | 客户 |

**⚠️ 前端的 `EXCHANGE_ACCEPTED` 应改为 `EXCHANGE_COMPLETED`**

### 通用终态（Final States）

| 后端 (Rust) | 前端 (TS) | 描述 |
|-----------|---------|------|
| Cancelled | CANCELLED | 订单取消 |

**前端还有 `REJECTED` 状态，后端未定义，需要确认用途**

## 前端多余状态分析

| 前端状态 | 后端是否有 | 用途 | 建议 |
|--------|---------|------|------|
| AFTER_SALE | ❌ ReturnRequested | 售后处理 | 重命名为 RETURN_REQUESTED |
| REJECTED | ❌ | 售后拒绝？ | 删除掉 |
| ACCEPTED | ❌ | (已删除) | - |
| STOCKED | ❌ | (已删除) | - |
这些多余状态不需要了

每个订单包含多个商品，在市场或客户未验收前，每个商品在订单中的默认状态为PENDING，在验收后会成SIGN,RETURNED或EXCHANGED。在验收阶段，当一个产品被验收后（当前商品状态称为SIGN,RETURNED或EXCHANGED），其实际数量不能再被编辑；
在验收阶段，只有每个产品单独从操作menu中对每个产品进行了验收后，才能显示“完成验收”button。

``` rust
pub(crate) struct OrderStateMachine;

impl OrderStateMachine {
    /// 获取下一个状态
    pub(crate) fn next_state(
        current: OrderStatus,
        action: OrderAction,
        actor: TenantType,
    ) -> Result<OrderStatus, TransitionError> {
        // 检查当前状态是否为终态
        if current.is_terminal() {
            return Err(TransitionError::TerminalState { status: current });
        }

        // 检查租户是否有权限执行该操作
        if !actor.can_perform_action(&action) {
            return Err(TransitionError::InvalidAction {
                current_status: current,
                action,
                actor,
            });
        }

        let next_status = match (current, action, actor) {
            // 市场给供应商分配订单
            (OrderStatus::Pending, OrderAction::AssignSupplier, TenantType::Market) => {
                OrderStatus::Assigned
            }

            // 供应商操作流程
            (OrderStatus::Assigned, OrderAction::StartPreparing, TenantType::Provider) => {
                OrderStatus::SupplierPreparing
            }
            (
                OrderStatus::SupplierPreparing,
                OrderAction::DeliverToMarket,
                TenantType::Provider,
            ) => OrderStatus::SupplierDelivering,

            // 市场正常接收流程
            (OrderStatus::SupplierDelivering, OrderAction::MarketInspect, TenantType::Market) => {
                OrderStatus::MarketInspecting
            }
            (OrderStatus::MarketInspecting, OrderAction::MarketAccept, TenantType::Market) => {
                OrderStatus::MarketAccepted
            }
            (OrderStatus::MarketAccepted, OrderAction::DeliverToCustomer, TenantType::Market) => {
                OrderStatus::MarketDelivering
            }
            (OrderStatus::MarketDelivering, OrderAction::CustomerInspect, TenantType::Customer) => {
                OrderStatus::CustomerInspecting
            }
            (OrderStatus::CustomerInspecting, OrderAction::Complete, TenantType::Customer) => {
                OrderStatus::Completed
            }

            // 市场验收请求退换货
            (OrderStatus::MarketInspecting, OrderAction::MarketReturn, TenantType::Market) => {
                OrderStatus::Returned // 市场申请退货场景暂时没有，暂时不做后续处理
            }
            (OrderStatus::MarketInspecting, OrderAction::MarketExchange, TenantType::Market) => {
                OrderStatus::ExchangeRequested
            }
            (OrderStatus::ExchangeRequested, OrderAction::StartPreparing, TenantType::Provider) => {
                OrderStatus::ExchangeInProgress
            }
            (
                OrderStatus::ExchangeInProgress,
                OrderAction::DeliverToMarket,
                TenantType::Provider,
            ) => OrderStatus::ExchangeDelivering,

            (OrderStatus::ExchangeDelivering, OrderAction::MarketInspect, TenantType::Market) => {
                OrderStatus::ExchangeInspecting
            }
            (OrderStatus::ExchangeInspecting, OrderAction::MarketAccept, TenantType::Market) => {
                OrderStatus::ExchangeNewDelivering // 只有一次换货，这里直接换货完毕
            }
            (
                OrderStatus::ExchangeNewDelivering,
                OrderAction::DeliverToCustomer,
                TenantType::Market,
            ) => OrderStatus::CustomerInspecting,

            // 客户验收异常流程
            // 客户要求换货
            (
                OrderStatus::CustomerInspecting,
                OrderAction::CustomerExchange,
                TenantType::Customer,
            ) => OrderStatus::ExchangeRequested,
          
            (OrderStatus::ReturnRequested, OrderAction::CustomerReturn, TenantType::Customer) => {
                OrderStatus::Returned // 退货直接退款，无需后续服务流程
            }
          
            // 取消订单（只有市场和客户可在非终态都可以取消）
            (_, OrderAction::Cancel, TenantType::Customer | TenantType::Market)
                if !current.is_terminal() =>
            {
                OrderStatus::Cancelled
            }

            // 默认情况：无效的状态转移
            _ => {
                return Err(TransitionError::InvalidAction {
                    current_status: current,
                    action,
                    actor,
                })
            }
        };

        Ok(next_status)
    }
}
``` 

## 迁移建议

### 第一步：同步状态定义
1. 将前端状态与后端保持一致
2. 删除未定义的状态
3. 重命名不一致的状态

### 第二步：添加状态工具函数
```typescript
// utils/orderStatusUtils.ts
export function getStatusFlow(status: OrderStatus): 'NORMAL' | 'RETURN' | 'EXCHANGE' | 'FINAL'
export function canTransition(from: OrderStatus, to: OrderStatus): boolean
export function getNextStatus(current: OrderStatus): OrderStatus[]
export function getStatusDisplay(status: OrderStatus, tenantType: string): string
```

### 第三步：更新组件逻辑
将硬编码的状态检查改为使用工具函数：
```typescript
// ❌ 之前
if (orderStatus === "SUPPLIER_PREPARING" || orderStatus === "EXCHANGE_IN_PROGRESS") { ... }

// ✅ 之后
if (canShowSaveButton(orderStatus, tenantType)) { ... }
```
